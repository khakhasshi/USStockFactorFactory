# 美股三层研究架构 A–E 预注册协议 v1

## 1. 研究问题

在完全相同的美股面板、训练安全时间切分、DSL、成本模型、任务顺序、收益机制轮转和候选评估预算下，分别估计以下增量：

| 对比 | 唯一新增组件 | 待检验问题 |
|---|---|---|
| B − A | 第一层算法搜索池 | 进化、代理模型和强化学习式调度是否优于广泛结构化随机搜索 |
| C − B | 第二层 Researcher LLM | LLM 审查并改进算法种子是否产生独立增量 |
| D − C | 第二层任务连续记忆 | 同一任务的训练安全反馈是否改善后续 LLM 候选 |
| E − D | 第三层 Governor LLM | 低频、单变量模板治理是否产生独立增量 |

任何组都不能在搜索、提示词、算法调度或元策略中读取 `META_HOLDOUT`、`FACTOR_VAULT` 或冻结评级结果。冻结评级仅在研究结束后单独运行，窗口为 2020-01-01 至面板最新日期。

## 2. 三层职责

### 第一层：Search Pool

- `structured_random`：按收益机制采样合法 DSL 语法树。
- `evolutionary`：从同任务、同机制的训练层优胜节点做局部变异。
- `surrogate_kernel`：一次生成 8 个合法候选，以表达式结构相似度核回归预测训练得分，并用不确定性奖励选取候选。
- `q_learning`：状态为“任务 × 收益机制”，动作是 `fresh` 或 `mutate`，用训练得分的有界样本均值更新 Q 值，并采用衰减 epsilon-greedy。
- UCB1 在上述算法之间分配候选预算；每个机制先完成确定性冷启动轮转。

这是一组小型、在线、可解释的算法，不宣称深度强化学习，也不使用不可审计的离线标签。

### 第二层：Researcher LLM

接收第一层的表达式、经济假设、算法来源和训练安全反馈。它只能保留种子或做一次有理由的结构改进；输出与种子的结构相似度不得低于 0.20，并必须通过 DSL、字段时点、收益机制、新颖性和变更轴验证。无效成员以 `llm_rejected` 持久化，不以随机候选冒充成功响应。

### 第三层：Governor LLM

低频读取训练安全的版本级汇总，仅能修改 MinerTemplate 允许字段。评价器、数据层、隔离层、接受门和冻结评级均为只读。A–D 固定同一模板，E 才启用 Governor。

## 3. 五组实验

| 组 | 第一层 | 第二层 | 连续记忆 | 第三层 |
|---|---|---|---|---|
| A | 仅结构化随机 | 关闭 | 关闭 | 关闭 |
| B | 完整算法池 | 关闭 | 关闭 | 关闭 |
| C | 完整算法池 | 开启 | 冷记忆 | 关闭 |
| D | 完整算法池 | 开启 | 任务连续记忆 | 关闭 |
| E | 完整算法池 | 开启 | 任务连续记忆 | 开启 |

五组各 120 个候选，固定策略步采用 5 seeds × 6 candidates = 30 个候选，避免预算在不完整 seed block 中结束。五个 worker 同时处于运行态，但全局最多同时执行两个全面板评价；LLM 等待、上下文生成和数据库写入仍可并行。

## 4. 指标与停止规则

主指标为训练层 `diversity_adjusted_training_meta_score`。次指标包括 gate 通过率、合法候选率、因子准入率、收益机制覆盖率、训练收益来源覆盖、墙钟时间和 LLM 调用数。
训练收益来源治理采用 `training_return_source_governance_v2`：相关阈值 0.85、目标 5 个独立来源、meta-score 权重 0.15；只读取训练层收益路径签名，且禁止跨实验因子准入。

任一组在候选预算、6 个外层步、4 小时或 60 次 LLM 调用中最先触达者停止。因子库为空是允许结果；每个合法或失败候选仍进入任务专属研究记录。

Provider 的认证、余额、限流、网络或配置错误属于基础设施故障，不是失败因子。第二层或第三层遇到这类错误时 worker 立即熔断，且不写入伪造的随机候选、不消耗候选评价预算；修复 provider 后可用同一幂等 campaign 请求恢复未完成组。

实验启动后不得修改数据窗口、任务、成本、方向策略、候选预算、提示词隔离规则或主指标。若运行时代码指纹发生变化，该组必须单独标记，不与原批次直接合并。

## 5. 运行接口

- `POST /api/campaigns/three-layer`：幂等创建并可同时启动 A–E。
- `GET /api/campaigns/three-layer/{campaign_id}`：查看五组 worker、候选、LLM 调用和第一层算法分配。
- `POST /api/engine/stop`：可按 `experiment_id` 停止单组；已提交节点保留。

默认实验标识为 `us-v668-three-layer-abcde-v4`。同名但实验标识或组别不一致时接口返回 409，绝不覆盖历史任务。
