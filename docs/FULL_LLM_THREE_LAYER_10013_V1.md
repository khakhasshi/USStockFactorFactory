# 10013 全 LLM 三层连续研究框架 V1

10013 将确定性 DSL、数据、回测、成本、未来函数检查、重复检查和准入门槛视为研究仪器，
而不是决策层。三层研究决策均由 LLM 完成，任何 provider 传输失败都会熔断，不能伪装成
随机提案。

## 三层职责

1. **L1 机制科学家**：可以不依赖算法种子，直接提出完整因子表达式；也可做单轴变异和
   定向修复。算法池只以 30% 概率提供可选灵感，L1 没有复制或贴近种子的义务。
2. **L2 研究主任**：读取训练安全的候选谱系、失败归因与 A/B 结果，修改搜索提示、上下文、
   多样性和候选策略；不能改数据、评分器或门槛。
3. **L3 科学总督**：低频管理机制组合、探索比例、研究目标、证伪规则和指令任期；不能直接
   写表达式，也不能访问冻结评级。

## 记忆与隔离

- L1 保存候选谱系、拒绝原因和修复记录。
- L2 保存策略假设、单变量修改及配对 cohort 结果。
- L3 保存机制组合、证据指纹、任期和证伪结果。
- 三层只接收训练安全反馈。2020 至最新可用日的冻结评级仅用于独立评级，绝不回流提示词。
- PIT 只披露，不作为快速研究或因子入库阻断项。

## 服务与任务

- 服务：`http://127.0.0.1:10013`
- 美股：多空，三个流动性/周期任务，正反双向训练后冻结方向。
- A 股：纯多，三个流动性/周期任务，正反双向训练选择只服务于研究阶段。
- 两个任务候选预算、因子目标和运行时长均不设停止上限，服务自动恢复。
- 两个 worker 可并行等待或调用 LLM；全面板评价由单槽信号量串行，防止内存放大。

## 审计判据

不能仅凭端口存活宣称全 LLM 正常。至少应看到每个任务的 `LLMCallAudit` 中出现
`mechanism_scientist`、`research_director`、`scientific_governor`，并检查 accepted/rejected、
provider、模型、耗时、证据指纹、指令 ID 和候选节点的 `direct_expression_authority=true`。
