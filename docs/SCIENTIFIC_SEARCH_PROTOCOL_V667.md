# 美股 V667 科学搜索协议

## 目标

V667 不以“尽快填充正式因子库”为目标，而是在有限预算内判断两层 LLM 是否产生了超过随机搜索的可重复增量。正式因子库可以为空；所有已评价候选进入任务研究记录库，按 task 内学习分降序排列。

## 七阶段执行边界

1. **冻结 V666**：保留节点、LLM 调用和外层证据，不与 V667 混用。
2. **有界运行**：候选总预算 120，最多 6 个外层步、4 小时或 60 次 LLM 调用，任一边界先到即停。
3. **高效候选生成**：一次内层 LLM 调用预注册 6 个候选；每个成员独立进行 DSL、字段来源、机制和语义校验。无效 LLM 成员记为 `llm_rejected`，不用随机候选偷换。
4. **三臂对照**：`random`、`llm_cold`、`llm_memory` 使用同样的 task/机制/种子/预算日程。节点保存 `experiment_arm`、`memory_mode` 和 `cohort_id`。
5. **配对外层统计**：候选与在位者使用 6 个相同 seed cohort，使用单边精确符号翻转检验。外层每次只允许一个模板字段变化；无实质变化时直接短路，仅在首次需要时暖启基线。
6. **真实研究树**：草稿与改进预声明 50/50，最大深度 3。改进节点必须指定唯一 `change_axis`，并保存 parent/depth/cohort。
7. **审计与回放**：引擎状态显示全局预算、ETA、LLM 调用数和已加载代码指纹。任务研究记录只返回训练安全指标，不返回原始 `gate_metrics`、HOLDOUT 或 Vault 证据。

## 数据时间边界

| 层 | 美股日期 | 研究中的用途 | LLM 可见 |
|---|---|---|---|
| INNER_PUBLIC | 2010-06-01 至 2019-12-31 | 内层候选学习与诊断 | 仅可见结构化训练反馈 |
| META_TRAIN | 2020-01-01 至 2022-12-31 | 硬门槛与外层比较 | 仅可见经过脱敏聚合的反馈 |
| META_HOLDOUT | 2023-01-01 至 2024-12-31 | 冻结方向后的独立硬门槛 | 否 |
| FACTOR_VAULT | 2025-01-01 至预声明边界 | 最终封存硬门槛 | 否 |
| FROZEN_RATING | 2020-01-01 至面板最新交易日 | 显式完整审计的长期评级；非独立样本外 | 否 |

任务的“研究可见时段”仍是 INNER_PUBLIC + META_TRAIN。方向冻结后，HOLDOUT 与 Vault 分别执行硬门槛；正式冻结评级使用 2020 至面板最新交易日的全窗口。评级跨越训练与私有层，因此只能解释为长期 NON-PIT 排序，不能解释为独立样本外证据，也不能进入任何 LLM 反馈。

## 判定标准

- 三臂必须使用相同候选预算和 cohort 日程，报告有效率、学习分分布、硬门通过率、收益来源数、重复率和单位 LLM 调用收益。
- 只有 `llm_memory` 相对 `llm_cold` 的配对增量稳定，才能声称连续记忆有实际作用。
- 只有 LLM 臂相对 `random` 有超额收益，才能声称两层 LLM 框架有实际作用。
- 所有门槛失败时允许正式因子库继续为空；不得将研究记录排名表述为可交易因子。

## 手动回测

美股手动回测可在每次请求中独立选择 `long_only` 或 `long_short`，不改写研究任务的默认组合模式。`long_only` 强制年化借券成本为 0；回测历史保存实际使用的组合版本。
