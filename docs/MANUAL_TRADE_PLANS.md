# 手工交易计划 v1

部署范围：美股 8765、A股日线 8767；不改动 8768 独立快照研究服务。

## 使用

1. 打开「交易计划」，选择「从回测创建实例」。或在回测历史中点击「创建计划」。
2. 本服务内输入已完成且账本 PASS 的 `step_event_v2_weighted_sleeves_v1` 回测 ID。美股示例841、A股示例853；ID不能跨数据库混用。
3. 核对冻结因子、方向、独立袖套权重、仓位、退出与费用定义；填写名称、真实分配本金、首次开仓日。新实例初始空仓、默认暂停，不继承回测期末资产。
4. 可手工生成某个尚未开盘的交易日计划，或启动每日自动生成。启动只是计划调度，不是自动交易授权。
5. 阅读开/平/加/减/持有清单、参考数量和金额、组合权重、风险条件与容量警示；可以导出 CSV。开盘人工检查跳空、现金、可卖量、停牌、借券和实时价格。
6. 收盘后按照实际交割单回填成交及费用，或导入 CSV。不得将建议数量直接当作实际成交。
7. 确认全部成交/未成交后锁定当日账本，下一份计划才能生成。确认前可以继续追加漏掉的成交；确认后历史不能追改。

## 语义与保障

- 回测定义、决策代码哈希、首次开仓日和资本在创建时冻结；换参数/代码需审核后建立新实例。
- 首次开仓日是调仓锚点，之后每 N 个交易所会话调仓，不按自然日或固定星期计算。不自动到期清仓。
- `exchange-calendars 4.13.2` 的 XNYS/XSHG 负责节假日、夏令时和半日市。超出日历覆盖范围时失败，不用工作日替代。
- 信号必须来自执行日前一个完整市场交易日；收盘后至少30分钟、数据日期连续完整才计算。此缓冲不保证供应商数据正确；不是严格 PIT 数据认证。
- 每个袖套调用事件引擎原有 `_target_quantities`、`_create_orders`、持仓生命周期与组合风控状态机；不使用多因子合成排名替代独立资金袖套。
- 每日回放只消费手工成交/现金费用记录，回测执行器被替换为“不成交”。不会因为建议买入或风险触发而伪造实际持仓。
- 分红、融资/借券费用可作为现金费用记录；实际费用不使用回测假设值冒充。出入金、实物初始持仓导入及修订交割单不在 v1 范围内。
- A股买入整手、T+1可卖量、纯多禁止超卖及现金账户余额在回填时校验；美股多空必须由人工核实借券和保证金。回填不是下单许可。
- 新建仓止损价基于参考收盘价，仅为预估；必须按实际成交成本重新计算。没有盘中数据时，不承诺实时止损通知或成交先后。实际成交当日只用收盘更新移动锚点，避免采用成交前发生的日内极值；因此不能宣称实盘与日线模拟完全相同。
- 复权因子变化触发 `CORPORATE_ACTION_REVIEW`。不会将回测“拆股/分红再投资代理”自动记成真实账户股票。此类实例需要独立核对处理，本版不支持自动恢复公司行为。
- 缺失持仓行情、历史输入修订、代码版本改变、待对账、数据不足等都会阻止生成。计划支持无操作日，不强行开仓。
- 同一实例/执行日只有一个不可变计划；输入保留逐会话hash及Parquet对象。重新读取返回原记录，服务重启不重复创建。
- 代码更新后需要重启服务。自动调度依赖本机服务常驻和行情更新，本机休眠时无法生成计划；恢复后只考虑尚未开盘的下一交易日，不补造过去可执行计划。

## 存储

同各自研究服务 PostgreSQL 数据库，不读写券商数据库：

- `manual_plan_instances`：冻结策略定义、状态、计算进度。
- `manual_plan_batches`：不可变计划快照、独立成交对账确认。
- `manual_plan_entries`：追加式手工成交、费用/分红现金调整。
- 数据输入：该服务 `FF_BACKTEST_ARTIFACT_ROOT/manual-plan-inputs/<SHA256>.parquet`。

数据库触发器禁止删除历史、修改源定义、覆盖计划快照或修改已记账条目。暂停和归档均不删除数据。无 API 密钥、无券商SDK调用、无订单提交接口。

CSV字段：`external_id,sleeve_id,date,symbol,quantity,price,fees,note`。买入数量为正，卖出为负；每批最多1000条。逐行提交并报告结果，失败行不回滚成功行；使用券商唯一成交编号安全重试。不会默认填充模拟价格。

## 验证记录（2026-09-20）

- 单元及回归测试覆盖美股纯多、美股多空、A股纯多、交易日锚定、收盘时点、过期阻断、部分成交、独立袖套、T+1、公司行为及非有限数拒绝。
- PostgreSQL临时隔离schema测试真实 HTTP API：来源冻结、计划幂等、证据不可变、CSV部分失败、成交去重、对账后锁定、归档只读。测试schema结束后清理，不触碰业务历史。
- 真实源回测841/853：按原始模拟本金，2026-09-18收盘信号、2026-09-21首次开仓，分别生成19/96个目标，组合目标权重94.692984%/91.356960%。没有确认成交或提交订单。
- 最终相关测试40项通过。8765和8767各保留实例 #1「功能验收示例（非真实账户）」，已经归档，未开启自动调度；可以只读查看首日计划，实际交割记录均为0。美股参考本金100万美元、A股1000万元仅沿用源回测，不能当作用户实际分配资金。
- 原有回测默认最低60交易日不变；计划仅通过显式参数允许单个信号日，并沿用完整历史预热及全截面DSL计算。

运行：`.venv/bin/python -m pytest tests/test_manual_trade_plans.py tests/test_manual_trade_plan_api.py tests/test_event_backtest.py tests/test_multi_factor_backtest.py tests/test_screener_engine.py -q`

边界：这不是无人值守实盘系统；账本与定仓测试通过不等于策略具有未来收益，也不等于所有真实市场执行约束已由机器验证。
