核心结论

冻结的是7个代表因子，但它们只构成6个组合袖套。U0010与U0013都属于长周期动量/波动调整趋势袖套，不能被当成两个完全独立的经济收益来源。其余五条分别代表价格冲击流动性、低绝对振幅、股量流动性、短期反转和价格关系。

2020–2024固定方案实验显示，按“六袖套等权、动量袖套内部两因子各半”构造的基准，在纯多和多空中都比七因子机械等权更稳健；2024协议内测试仍支持等权袖套。
但最新严格嵌套优化给出 NO_COMBINATION。2010–2016训练看似有效的候选，在2017–2019验证中收益和Sharpe转负，未通过FDR、最差年度、盈利年度比例与压力成本门槛。因此当前证据支持“保留研究资产、继续复核”，不支持直接晋升为正式组合。

研究结论 七条公式可作为多因子研究组件池；默认基准应采用六袖套等权，而不是把七条公式视为七个同权独立来源。任何“最优权重”必须在新的预声明窗口中重新验证。

四、第二轮嵌套袖套权重（2020–2024）

2020–2022拟合、2023选择政策、2024协议内测试；所有六个袖套必须保留，学习权重向等权收缩50%，单袖套上限30%。

纯多

2023选择了风险/IC综合权重：验证年化4.15%、Sharpe 1.066，高于等权的3.18%与0.812。但2024最终测试中，学习权重年化11.55%、Sharpe 2.413，反而低于等权的13.56%与2.767。

多空

所有学习政策在2023均未通过相对等权门槛，系统回退到六袖套等权。2024最终测试净年化23.08%、Sharpe 2.852；步进复测年化20.93%、Sharpe 2.295、回撤6.46%。

第二轮只对“权重选择”做了局部嵌套。七个因子身份和方向来自覆盖2020–2026的榜单，所以2024并非全局未见样本，不能当作最终实盘批准。

七、已知边界与下一步

不能忽略的边界

  • 面板为当前成分投影，标记 NON-PIT；本项目按快速研究口径使用，但不应声称生产可交易。
  • 共同窗口榜单参与了因子身份与方向筛选，2020–2026不是全局 untouched holdout。
  • U0006只是单例簇；U0012只有两个成员，稳定性证据弱。
  • U0005使用绝对价差，可能带价格水平暴露；U0002/U0001混合价格与成交额代理，需做尺度与容量归因。
  • 多空结果包含300 BPS年借券代理，但不代表逐股可借、召回和拥挤成本。

科学的下一轮

  1. 冻结六袖套等权为唯一基准，不再用本报告窗口调方向。
  2. 逐袖套做规模、价格、波动、流动性和行业暴露中性化归因。
  3. 将U0006、U0012作为“待证实袖套”，分别做删除消融与替代表达式复核。
  4. 使用滚动walk-forward比较六袖套等权、风险预算与收缩权重。
  5. 只在验证门槛通过后读取冻结评级，并输出StepEvent账本与成本压力。
当前正式判断：RESEARCH_ONLY / NO_COMBINATION。七条代表因子值得继续研究，但最新嵌套验证不支持直接采用优化权重。
