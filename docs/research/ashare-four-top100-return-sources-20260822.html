这7个不是正式因子库晋升结果。它们的身份和方向都受全窗口榜单影响；这里回答的是去重、归因和研究优先级，不是 untouched holdout 或实盘批准。

一、统一审计口径

四个冻结榜单

  • 内部样本外事件榜Top100
  • 内部全区间双向榜Top100
  • 外部联合库中A股来源Top100
  • 外部联合库中美股来源Top100

重放与去重

  • 方向严格复制原榜，不在共同窗口重新择向
  • 全部按A股纯多基准主动收益比较
  • 2020-01-01至2026-08-20，共320个5日收益期
  • |ρ|≥0.80合并为同一经济收益簇

外部联合库中4个 origin_scope=both 的代表被排除在两个外部子榜之外，防止同一来源同时占据A股库榜和美股库榜席位。41个原始公式在不同榜中出现方向冲突，因此无符号聚类是主答案，有向聚类只作可交易方向诊断。

阈值敏感性：|ρ|从0.70、0.75、0.80、0.85、0.90、0.95提高时，簇数依次为57、74、88、116、143、183；对应有效来源约10.40、11.98、13.65、13.51、15.84、33.37。结论是“十几个主要来源”，而不是精确迷信88这个阈值点。

三个直接结论

  1. 内部事件榜是明显的2023–2024阶段簇。该阶段100/100为正，2025–最新却0/100为正；这更像共同的阶段暴露，不是100条独立Alpha。
  2. 外部A股库是目前最有用的候选来源。它在最近阶段仍有82/100为正，但其榜单本身使用全窗口筛选，所以100/100全窗为正带有选择效应，不能当样本外胜率。
  3. 美股公式直接迁移A股总体失败。它触达54个簇、表面多样性最高，但全窗仅18个正年化，中位Sharpe为−0.793；跨市场新颖不等于跨市场有效。

四、不能被忽略的稳定性和归因边界

证据风险

  • 全窗口参与了榜单筛选与方向冻结，三阶段切片是稳定性描述，不是全局样本外。
  • 外部A股库的强结果包含全窗口择优效应；真正新增证据应从本次冻结之后开始。
  • 年度并非全部为正：七袖套只是三个宽阶段为正，不能称“逐年稳定”。
  • 47个单例簇缺乏复现，不计入核心袖套。

经济暴露风险

  • 市值、成交额、量比和大单字段可能共享规模/流动性暴露。
  • U0004用绝对流通市值的时间标准差，可能主要是大盘尺度，而不是新Alpha。
  • 资金流与量比袖套相关0.710；若采用更保守0.70阈值，应合并成一个流动性/资金流大袖套。
  • A股公式迁移美股与美股公式迁移A股都应单独冻结方向，不能默认跨市场同号。

RESEARCH_ONLY 当前不输出“正式组合已通过”，也不把13.65或7解释为可交易Alpha的精确数量。

五、下一轮组合实验建议

  1. 以七袖套等权为唯一基准；若采用0.70保守口径，则先合并U0003与U0026，再做六袖套等权。
  2. 每个袖套先做市值、流动性、波动和行业暴露回归；若中性化后主动收益消失，降级为风险暴露而非Alpha。
  3. 做逐袖套删除消融、相关性滚动窗口与成本压力；重点审查U0012最近衰减、U0015最近接近零、U0021高回撤。
  4. 程序化优化只允许收缩权重或风险预算，不重新搜索方向；所有学习方案必须优于等权并通过2025–最新压力。
  5. 从2026-08-22起建立真正前瞻冻结记录，后续数据只追加，不回改本次身份、方向和代表式。
