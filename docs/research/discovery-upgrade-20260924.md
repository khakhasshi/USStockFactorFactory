# 双市场因子发现优化 · 2026-09-24

适用：美股 8765 与 A 股日线 8767。不修改 8768、不切换数据源、不调整 PIT 政策，不降低正式晋级门槛。历史账本、原评分和数据库保留；新增诊断字段不回填为虚构的历史证据。

## 已实现

1. **残差搜索正确性**：平均并列排名，常数相关性为零；未预测的暖启动、embargo 和无效行使用 NaN 并从 OOF 评分排除。训练折独立拟合标准化，按完整日期隔离。
2. **联合重拟合 Beam**：对原组合和每次扩展分别执行同折 Ridge 训练；支持负系数、最多三层搜索（默认两层）和固定联合拟合预算（默认 64 次）。只保留正的残差、整体增量和边际增量，1e-6 数值容差。
3. **样本预筛**：跨日期常数、有限值覆盖不足 20%、有效变动日期不足 20% 的信号不能进入残差学习。模型中残余缺失值按中性 rank 填充，产物明确记录规则；这不是可成交性证明。
4. **持续刷新**：计数来自全任务成功评价的唯一表达式，不再受 200/240 条精英存档上限影响，也不会漏掉异步晚完成的旧 ID。
5. **预算归因**：分别记录请求算法、实际执行算法、回退原因；随机回退不能记为成功执行 Residual/ML。MCTS 子节点访问数来自已发生的父子提案，不再恒为 1；它仍是启发式搜索，不宣称完整通用 MCTS。
6. **Qlib 蒸馏**：增加条件门控表达式；进入搜索池前测量 DSL 代理与残差教师的验证期 RankIC 保真度。至少 30 个有效日期且绝对相关性不低于 0.1；常数教师无效。保真度来自抽样股票池，仍需完整 DSL 评价。
7. **证据绑定**：LLM 改写表达式后撤销种子的实测增量资格，只保留父证据供追溯。提示词要求失败分类、单轴修改、预声明改进方向。
8. **三类评分展示**：探索分、独立质量、组合增量分开；独立质量是训练诊断，不替换旧学习分和正式评级。缺少证据为未知，不当作零分或通过。亏损/压力成本失败时独立质量上限 24.9。
9. **组合候选池**：内容寻址 JSON、SHA256 验证、原子最新指针；研究记录页展示路径、ΔRankIC 和稳定性。候选池不是冻结交易权重，不授予正式资格。
10. **正式证据展示**：事件、不可变输入、DSR/PBO 阻断时标记 audit_blocked；新增向量/事件指标并列比较。两种执行模型不要求收益完全相等。无 Git 的部署副本也可冻结白名单应用源码，不读取凭证/运行数据。
11. **等预算工具**：独立反馈与 RNG，固定每臂唯一评价预算，随机交错顺序，失败评价计费、重复重采样有上限，逐次产物与进度落盘。冻结面板/代码/合同；不操作研究任务和正式因子库。

## 验证及边界

- 全套回归测试覆盖并列排名、常数、缺失值、暖启动、embargo、负载荷、组合扩展、拟合预算、回退归因、证据哈希、非 Git 部署、LLM 改写、刷新计数、对照预算。
- 真实美股残差小样本：9,966 行、461 个日期；有效 OOF 7,413 行、排除 2,553 行，6 次联合拟合，约 5.01 秒。
- 真实 A 股残差小样本：9,831 行、283 个日期；有效 OOF 7,181 行、排除 2,650 行，6 次联合拟合，约 6.45 秒。
- 两者只使用训练层，最晚样本分别为 2022-12-21 / 2022-12-22，没有读取 HOLDOUT/Vault。耗时是本机抽样冒烟测试，不是生产加速比。
- 两市场均完成 structured_random / grammar_enumerative 每臂一次的真实评价验收。该样本量只能确认工具可运行，不能排名算法。
- Qlib 实际联合训练验收：每市场 50,000 行预算、3 折、每组 12 个蒸馏候选；美股 8 个、A 股 7 个通过教师保真度，但两市场模型整体搜索资格均未通过，未强行放行。产物在 `var/reports/qlib-joint/tasks/upgrade-v5-smoke-20260924/`。首次 20,000 行预算被完整日期最低样本门槛拒绝后，增加预算完成，没有降低门槛。
- OOF 日度 IC 使用预分组索引，避免每个日期重复扫描整张矩阵；与显式日期掩码计算有一致性回归测试，没有改变统计口径。
- 评分权重尚未经过前瞻校准；尚不能证明新增方法提高未来收益。
- 联合 OOF 是自适应训练证据，不是独立样本外。组合增量池尚未自动触发成对事件收益比较；费后组合增益仍须在现有组合优化/事件回测中单独确认。
- GBDT Residual 臂仍是“表达式结构 → OOF 质量”的代理模型，不是逐股票收益模型；Qlib 联合模型是另一条真实样本级模型路径。
- CLI 默认未预加载 Residual/Qlib 产物，选这些臂时会如实统计回退，不能把这类结果用于评价真正 Residual/Qlib 模型。
- 本轮不自动启动持续挖掘、不购买或调用 LLM、不重审历史全库，不把历史任务伪装为采用新协议。

## 对照命令

在对应项目目录运行（同一市场内比较，不把两市场的分数混排）：

```sh
POLARS_MAX_THREADS=4 .venv/bin/python scripts/benchmark_discovery.py --market us --budget 20 --arms structured_random grammar_enumerative evolutionary
POLARS_MAX_THREADS=4 .venv/bin/python scripts/benchmark_discovery.py --market ashare --budget 20 --arms structured_random grammar_enumerative evolutionary
```

产物在 `var/reports/discovery-benchmark/`，包含 `contract.json`、`progress.json`、每次 attempt 文件和 `report.json`。输出目录不可覆盖；中断保留现有证据，当前 CLI 不自动续跑。
