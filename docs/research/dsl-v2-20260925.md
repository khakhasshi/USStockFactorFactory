# DSL v2：算子扩展与相关性语义迁移

版本：`factorfactory.dsl/v2-20260925`。适用：美股 8765、A 股日线 8767。

## 历史兼容

旧 `ts_corr(x,y,w)` 保留原公式及 epsilon：总体协方差除以样本标准差之积，完整非退化线性窗口约为 `(w-1)/w`，不能按标准 Pearson 解释。历史表达式、节点、分数不自动改写。

新研究显式使用 `ts_corr_v2(x,y,w)`。逐窗口先中心化再求内积，避免大价格偏置下差分矩公式的消减误差。完整配对有效窗口，零方差返回 null，结果约束在 [-1,1]。新旧名字具有不同表达式哈希。历史迁移采用复制表达式后独立复评，不覆盖旧证据；训练对比不能替代正式事件、HOLDOUT、Vault 审计。

DSL 修订、表达式算子配置、代码指纹进入评价/回测证据。新 Qlib 特征目录与联合模型缓存更换版本，缓存键含完整表达式，而非仅特征名。旧存储结果仍属于其原始版本。

## 新增 17 个算子

| 算子 | 语义与约束 |
|---|---|
| `ts_corr_v2(x,y,w)` | 标准 Pearson，完整配对窗口，零方差 null |
| `ts_beta(y,x,w)` | 含截距滚动 OLS 的 beta；x 零方差 null |
| `ts_residual(y,x,w)` | 上述回归当前观测残差；不同于时间趋势 `ts_resi` |
| `cs_residual(y,x)` | 逐日配对有效截面含截距残差，至少 3 个样本 |
| `where(cond,a,b)` | 非零选 a，否则 b；缺条件 null，不是交易开关指令 |
| `ts_count(cond,w)` | 完整窗口条件非零次数，缺失不是 false |
| `ts_mean_if(x,cond,w)` | 窗口条件均值；无命中或不完整窗口 null |
| `ts_median(x,w)` | 完整窗口中位数 |
| `ts_mad(x,w)` | 同一窗口对其中位数的绝对偏差中位数 |
| `ts_robust_zscore(x,w)` | `(x-median)/(1.4826*MAD)`，MAD 为零 null |
| `ts_decay_linear(x,w)` | 从旧到新 1..w 的归一化权重均值 |
| `ts_ewm(x,w)` | 有限 w 日、alpha=2/(w+1) 的归一化指数均值；不是递归无限 EMA |
| `ts_drawdown(x,w)` | 当前正价格/窗口正价格最大值-1；不是窗口最大回撤 |
| `ts_bars_since(cond,w)` | 最近真条件距今天数，今日为 0，无命中 null |
| `ts_streak(cond,w)` | 当前连续真条件长度，0..w |
| `group_rank(x,g)` | 当日同组并列平均百分位排名，至少 2 个有效样本 |
| `group_zscore(x,g)` | 当日同组样本标准化，至少 2 个有效样本且方差非零 |

时序统计按证券分组、交易日期排序，仅向后观察。窗口按该证券面板有效行计数，不凭空补停牌数据；标签和交易日对齐仍由统一市场日历控制。组 g 只能使用实际白名单字段或显式离散表达式；没有行业字段时不得宣称行业中性，可使用成交量状态等分组。缺失和非有限输入不会被静默变成零信号。

## 搜索接入

- LLM 提示词使用统一 43 项新提案算子目录，明确标准相关新名字；用户文档保留全部 44 项（含 legacy）。
- 机制家族新增字段感知模板，Grammar、MAP-Elites、MCTS、Novelty 共用；Evolutionary/TPE 的新变异包含平滑、稳健化、条件门控。
- Residual OOF/GBDT 的候选生成与变异复用新语法；Qlib 联合学习额外物化 DSL2 扩展特征并允许蒸馏成 DSL，仍须经过统一评价。
- 算子可用不等于强迫所有候选使用新算子；必须保留探索预算、多重检验、机制检查和低成本预筛。
- 标准相关、条件和分组计算不改变成本、成交时点、风控、评分门槛或正式准入流程。

## 预热与验证

嵌套窗口计算完整回看长度，同时修复既有 quantile/slope/rsquare/resi/argmax/argmin 缺少预热计数的问题，取消静默 1000 行截断。因此旧表达式若以前预热不足，新跑可能有更多有效样本；这是显式预热修复，不是旧 ts_corr 算术变更。

验证入口：`tests/test_dsl_v2.py` 与 `scripts/validate_dsl_v2.py`。覆盖 NumPy 真值、零方差、空值、预热、未来扰动、乱序、缓存精确一致、提示词和程序生成器可达性。真实双市场训练/完整向量/事件账本比较及历史相关表达式复制复评结果位于 `var/reports/dsl-v2-20260925/report.json`。复评不向生产试验账本写入训练收益，也不把测试结果回灌 LLM。

实际发现的 Polars 带权滚动遇 null 崩溃已在新算子中通过“内核暂填零 + 完整有效窗口掩码”处理；输出仍严格保留缺失。标准相关使用分块稳定算法，比不稳定的差分矩公式可能更贵，不承诺算子扩展提高每秒评估数或保证找到 Alpha。
