# 重要研究文档目录

这里保存项目中需要长期保留、可直接阅读的 HTML 研究结论。

## 新增文档

1. 在本目录新增一个自包含的 `.html` 文件。文件名只使用小写字母、数字和连字符。
2. 在 `catalog.json` 的 `documents` 数组登记元数据：
   - `slug`：稳定且唯一，发布后不要复用；
   - `file`：本目录内的 HTML 文件名，禁止子目录和路径跳转；
   - `title`、`subtitle`、`summary`、`category`、`status`；
   - `published_at`、`updated_at`：`YYYY-MM-DD`；
   - `tags`：用于“文档”页面搜索。
3. 刷新10010的“文档”页面。目录和 SHA256 会由后端实时读取，无需修改前端。

## 版本原则

- 已发布结论原则上不覆盖；口径或结论发生实质变化时新增版本和 slug。
- 报告必须列出原始工件路径、协议、时间窗口、成本和已知限制。
- 失败和 `NO_COMBINATION` 也是正式研究结论，不得隐藏最佳被拒候选的证据。
- HTML 只读提供，不支持页面内上传、删除或改写文件。
